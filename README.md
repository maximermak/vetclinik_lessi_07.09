# Pussy Cat — сайт ветеринарної клініки

Лендінг ветклініки та грумінг-салону з формою онлайн-запису.
Заявки миттєво надходять адміністратору в Telegram.

**Стек:** Node.js + Express + EJS, без збірки та фронтенд-фреймворків.

## Запуск

```bash
npm install
cp .env.example .env   # якщо .env ще немає
npm start              # http://localhost:3000
```

Для розробки з автоперезапуском: `npm run dev`.

## Налаштування Telegram

1. Токен бота вже прописаний у `.env` (`TELEGRAM_BOT_TOKEN`) — бот
   [@pussycatsalon_bot](https://t.me/pussycatsalon_bot).
2. Визначте, **куди** бот надсилатиме заявки:
   - **особисті повідомлення** — відкрийте [@pussycatsalon_bot](https://t.me/pussycatsalon_bot)
     і натисніть «Start»;
   - **спільна група** (рекомендовано — бачить уся адміністрація) — створіть групу,
     додайте туди бота і напишіть у ній будь-яке повідомлення.
3. Виконайте:

   ```bash
   npm run chat-id
   ```

   Скрипт покаже список чатів з їхніми ID.
4. Скопіюйте потрібний ID у `.env`:

   ```
   TELEGRAM_CHAT_ID=-1001234567890
   ```

5. Перезапустіть сервер. Перевірити готовність: `curl localhost:3000/health`
   → поле `"telegram": true`.

Зараз у `.env` вже прописаний особистий чат власника. Коли зʼявиться спільна
група адміністрації — замініть `TELEGRAM_CHAT_ID` на її ID (у груп він
відʼємний, напр. `-1001234567890`).

## Структура

```
server.js              маршрути та віддача сторінки
src/data.js            увесь контент: послуги, графік, телефони, відгуки, FAQ
src/telegram.js        формування та надсилання повідомлення в Telegram
src/validate.js        перевірка полів заявки
views/index.ejs        головна сторінка
views/partials/        шапка, підвал, набір SVG-іконок
public/css/style.css   стилі (палітра — у CSS-змінних на початку файлу)
public/js/app.js       меню, маска телефону, відправка форми
scripts/get-chat-id.js допоміжний скрипт для пошуку chat_id
```

## Правки контенту

Майже все редагується в одному файлі — `src/data.js`:
телефони, графік роботи, перелік послуг, грумінг, переваги, відгуки, FAQ.

Адреса, посилання на Google Maps і відгуки — реальні, з картки клініки
(вул. Олександра Олеся, 21, Харків). Російськомовні відгуки перекладені українською.

## Рейтинг з Google

У героєві показуються оцінка та кількість відгуків. За замовчуванням беруться
запасні значення з `src/data.js` (`4,9` і `181`).

Якщо додати в `.env` ключ `GOOGLE_MAPS_API_KEY`, сервер сам оновлюватиме
ці цифри двічі на добу через Places API (New):

1. У Google Cloud Console увімкніть **Places API (New)** і створіть ключ.
2. Впишіть його в `.env` і перезапустіть сервер.
3. Перевірка: `curl localhost:3000/health` → у полі `googleRating`
   має зʼявитись `"live": true`.

Оновлення відбувається у фоні за таймером, тому запити відвідувачів ніколи
не чекають на відповідь Google. Якщо Google недоступний або ключ невірний —
сайт мовчки показує запасні значення з `data.js`, нічого не ламається.
Place ID клініки лежить у `src/data.js` (`clinic.placeId`).

Палітра сайту взята з фасаду клініки і задана змінними на початку
`public/css/style.css` (`--red`, `--yellow`, `--brown`, `--cream`).

## Форма запису

Форма існує у двох місцях і рендериться з одного файлу
`views/partials/form.ejs` (параметр `prefix` робить id унікальними):

- секція «Онлайн-запис» на сторінці;
- модальне вікно, яке відкривають усі кнопки «Записатись»
  (`data-modal-open`). Кнопка в картці послуги ще й підставляє цю послугу
  в поле — через `data-service`.

Поля: вид тварини (кіт / собака / інша), ім’я, телефон з маскою,
вік тварини, послуга, дата й час візиту та коментар. Вік у повідомленні
відмінюється українською: `1 рік`, `3 роки`, `5 років`, `8 місяців`.

Власні контроли замість системних — сегментований перемикач, лічильник
віку, випадний список і календар — описані в кінці `public/css/style.css`
і оживають у `public/js/app.js`. Список підтримує клавіатуру:
стрілки, Home/End, Enter, Escape.

Календар сам рахує вільні слоти з графіка клініки (`scheduleByWeekday`
у `src/data.js`): крок 30 хвилин, останній слот — за 30 хвилин до закриття,
на сьогодні показуються лише часи не раніше ніж через годину. Дні, коли
запис уже неможливий, стають неактивними. Записатись можна на 60 днів уперед.

## Політика конфіденційності

Сторінка `/privacy` (`views/privacy.ejs`) складена за Законом України
«Про захист персональних даних» № 2297-VI: хто володілець даних, що
збираємо, навіщо, кому передаємо (Telegram як канал доставки), скільки
зберігаємо, права людини за статтею 8.

У формі є обовʼязковий чекбокс згоди — його перевіряє і браузер,
і сервер (`required` у розмітці можна обійти, тому дублюємо
в `src/validate.js`).

**Обовʼязково заповнити перед запуском** — `clinic.legal` у `src/data.js`:
назва ФОП/ТОВ, РНОКПП або ЄДРПОУ та пошта для звернень. Зараз там
заглушки в кутових дужках, і без них сторінка юридично неповна.
Текст написаний як робоча основа — перед публікацією варто показати юристу.

## Захист форми від спаму

- приховане поле-приманка (honeypot) — заповнені ботом заявки тихо відкидаються;
- обмеження: не більше 5 заявок з однієї IP-адреси за 10 хвилин;
- валідація імені та номера телефону на сервері.

Якщо заявку не вдалося доставити в Telegram, вона друкується в лог сервера —
не загубиться навіть при збої месенджера.

## Деплой

Потрібен Node.js 18+. На сервері задайте змінні `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHAT_ID`, `PORT` та запустіть `npm start` під наглядом
процес-менеджера (pm2, systemd). Файл `.env` у git не потрапляє.
